# 💘 Valentine's "Escape the No" Game

A playful, interactive Valentine's Day web game where the "No" button keeps running away — making it impossible to say no!  
Perfect for a fun, memorable Valentine's proposal or just a cute surprise for someone special.

> *"You can click 'No' all you want… but love always finds a way!"* ❤️

---

## 🎮 How It Works

1. The page asks: **"Will you be my Valentine?"**
2. There are two buttons:
   - **Yes, I will!** → Triggers a celebration with falling hearts and a sweet message.
   - **No** → Makes the button *escape* to a random spot on the screen with a funny/sassy message in a speech bubble.
3. Each click on "No" changes the bubble text and moves the button again.
4. Eventually, the player gets tired (or amused) and clicks **"Yes"** — because you literally can't say no forever! 😉

---

## ✨ Features

- **Running "No" Button** — The "No" button moves randomly on every click.
- **Funny/Sassy Messages** — 15+ changing responses in a speech bubble.
- **Celebration Mode** — Falling hearts, animated text, and a romantic message after "Yes."
- **Romantic Styling** — Soft pink theme, floral background, elegant fonts.
- **Mobile-Friendly** — Works on phones, tablets, and desktops.

## 🚀 How to Use / Deploy

1. **Clone or Download** this repository.
2. Open `index.html` in any modern browser.
3. **Send the link** to your Valentine — or play it together in person!
4. Watch them try to click "No" until they give up and say **"Yes!"** ❤️

---

## 🎨 Customization Ideas

- **Change the messages** in the `messages` array in the `<script>`.
- **Replace the background** with a personal photo.
- **Add your names** in the heading.
- **Change the falling emojis** to inside jokes or favorite symbols.
- **Add background music** when they click "Yes."
